CHƯƠNG 1: GIỚI THIỆU VỀ JAVA VÀ CÁC KHÁI NIỆM CƠ BẢN

Mục tiêu chương

  • Hiểu được lịch sử ra đời, đặc điểm và ứng dụng của ngôn ngữ Java.
  • Biết cách cài đặt môi trường lập trình Java (JDK).
  • Nắm được cấu trúc cơ bản của một chương trình Java.
  • Hiểu và sử dụng được biến, hằng, kiểu dữ liệu, toán tử.
  • Biết cách nhập dữ liệu từ bàn phím và xuất dữ liệu ra màn hình.

PHẦN LÝ THUYẾT

1.1. Giới thiệu về ngôn ngữ lập trình Java

1.1.1. Lịch sử hình thành

Java được khởi đầu bởi James Gosling và nhóm kỹ sư tại hãng Sun Microsystems vào năm 1991, ban đầu với tên gọi Oak. Đến năm 1995, ngôn ngữ này chính thức được đổi tên thành Java và công bố rộng rãi. Năm 2010, Oracle mua lại Sun Microsystems và trở thành chủ sở hữu hiện tại của Java.

Java nổi tiếng với khẩu hiệu: "Write Once, Run Anywhere" (Viết một lần, chạy mọi nơi) nhờ cơ chế biên dịch sang bytecode và chạy trên Máy ảo Java (JVM – Java Virtual Machine).

1.1.2. Đặc điểm của Java

  • Hướng đối tượng (OOP): Tổ chức chương trình thành các lớp và đối tượng.
  • Độc lập nền tảng: Cùng một file bytecode chạy được trên nhiều hệ điều hành (Windows, Linux, macOS…).
  • Đơn giản: Loại bỏ các khái niệm phức tạp như con trỏ, đa kế thừa lớp.
  • An toàn: Có cơ chế kiểm soát bộ nhớ, không cho phép truy cập trực tiếp bộ nhớ.
  • Mạnh mẽ: Có cơ chế thu gom rác tự động (Garbage Collector) và xử lý ngoại lệ.
  • Đa luồng (Multithreading): Cho phép thực hiện nhiều công việc song song.
  • Phân tán: Hỗ trợ lập trình mạng, tính toán phân tán mạnh mẽ.

1.1.4. Ứng dụng của Java

  • Phát triển ứng dụng máy tính để bàn (Desktop).
  • Phát triển ứng dụng Web (Servlet, JSP, Spring Boot…).
  • Phát triển ứng dụng di động Android.
  • Lập trình máy chủ, hệ thống doanh nghiệp lớn.
  • Phát triển game, hệ thống nhúng, ứng dụng IoT.

1.2. Cài đặt môi trường lập trình Java

1.2.1. Các thành phần cần cài đặt

  • JDK (Java Development Kit): Bộ công cụ phát triển Java, bao gồm trình biên dịch javac, máy ảo java và các thư viện chuẩn.
  • IDE (Integrated Development Environment): Môi trường phát triển tích hợp như Eclipse, IntelliJ IDEA, NetBeans (không bắt buộc nhưng rất tiện lợi).
  • Trình soạn thảo văn bản: Notepad, Notepad++, VS Code… nếu lập trình không dùng IDE.

1.2.2. Các bước cài đặt

  1. Truy cập trang chủ Oracle (hoặc Adoptium) và tải JDK phiên bản phù hợp với hệ điều hành.
  2. Chạy bộ cài đặt và làm theo hướng dẫn.
  3. Thiết lập biến môi trường JAVA_HOME trỏ tới thư mục cài JDK và thêm %JAVA_HOME%\bin (Windows) hoặc $JAVA_HOME/bin (Linux/macOS) vào biến PATH.
  4. Kiểm tra bằng cách mở Command Prompt / Terminal và gõ:
java -version
javac -version

Nếu hiển thị thông tin phiên bản Java là bạn đã cài đặt thành công.

1.2.3. Quy trình biên dịch và thực thi chương trình Java

  1. Soạn thảo: Viết mã nguồn vào file có đuôi .java.
  2. Biên dịch: Dùng lệnh javac TenFile.java để tạo ra file .class chứa bytecode.
  3. Thực thi: Dùng lệnh java TenFile để JVM nạp bytecode và chạy chương trình.
     [Mã nguồn .java] --(javac)--> [Bytecode .class] --(JVM)--> [Chạy trên HĐH]

1.3. Cấu trúc cơ bản của một chương trình Java

1.3.1. Ví dụ chương trình đầu tiên

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Xin chao the gioi Java!");
    }
}

1.3.2. Giải thích các thành phần

  • public: Từ khóa chỉ phạm vi truy cập công khai.
  • class HelloWorld: Khai báo một lớp có tên HelloWorld. Tên lớp phải trùng với tên file (HelloWorld.java).
  • public static void main(String[] args): Là phương thức đặc biệt – điểm bắt đầu thực thi của mọi chương trình Java.
  • System.out.println(...): Lệnh in nội dung ra màn hình và xuống dòng.
  • { }: Cặp ngoặc nhọn bao khối lệnh.
  • ;: Kết thúc một câu lệnh.

1.4. Biến, hằng và kiểu dữ liệu

1.4.1. Biến (Variable)

Biến là một vùng nhớ có tên dùng để lưu trữ dữ liệu. Giá trị của biến có thể thay đổi trong quá trình chương trình chạy.

kieuDuLieu tenBien;                 // Khai báo
kieuDuLieu tenBien = giaTri;        // Khai báo và khởi tạo
kieuDuLieu a, b, c;                 // Khai báo nhiều biến cùng kiểu
    
int tuoi = 20;
double diemTrungBinh = 8.5;
String hoTen = "Nguyen Van A";
boolean daTotNghiep = true;

1.4.2. Hằng số (Constant)

Hằng là biến có giá trị không thay đổi trong suốt chương trình. Dùng từ khóa final khi khai báo.

final double PI = 3.14159;
final int MAX_SINH_VIEN = 100;

1.4.4. Kiểu dữ liệu tham chiếu (Reference Types)

Ngoài 8 kiểu nguyên thủy, Java còn có các kiểu tham chiếu như String, mảng, lớp, interface…

String hoTen = "Tran Thi B";
String diaChi = "Ha Noi";

1.4.5. Ép kiểu (Type Casting)

  • Ép kiểu ngầm định (widening): Từ kiểu nhỏ sang kiểu lớn, không mất dữ liệu. Ví dụ: int i = 10; double d = i;
  • Ép kiểu tường minh (narrowing): Từ kiểu lớn sang kiểu nhỏ, có thể mất dữ liệu. Ví dụ: double d = 9.7; int i = (int) d; // i = 9

1.4.6. Ví dụ tổng hợp

public class KieuDuLieu {
    public static void main(String[] args) {
        int a = 10;
        int b = 3;
        double thuong = (double) a / b;
        System.out.println("Thuong = " + thuong);

        char chuCai = 'J';
        String ten = "Java";
        boolean hopLe = true;
        final double PI = 3.14159;
        double chuVi = 2 * PI * 5;

        System.out.println("Ky tu: " + chuCai);
        System.out.println("Ten: " + ten);
        System.out.println("Hop le: " + hopLe);
        System.out.println("Chu vi hinh tron r=5: " + chuVi);
    }
}

1.6. Nhập xuất dữ liệu trong Java

1.6.1. Xuất dữ liệu với System.out

  • System.out.print(...): In ra màn hình không xuống dòng.
  • System.out.println(...): In ra màn hình và xuống dòng.
  • System.out.printf(...): In theo định dạng (giống C).
int tuoi = 20;
String ten = "An";
System.out.print("Xin chao ");
System.out.println(ten);
System.out.println("Tuoi: " + tuoi);
System.out.printf("Ten: %s, Tuoi: %d%n", ten, tuoi);
System.out.printf("Diem: %.2f%n", 8.456);

Các ký tự định dạng thường dùng với printf:

Ký tựÝ nghĩa
%dSố nguyên
%fSố thực (mặc định 6 chữ số sau dấu phẩy)
%.2fSố thực với 2 chữ số sau dấu phẩy
%sChuỗi
%cKý tự
%bBoolean
%nXuống dòng (an toàn đa nền tảng)

1.6.2. Nhập dữ liệu với Scanner

Để nhập dữ liệu từ bàn phím, Java sử dụng lớp Scanner thuộc gói java.util.

import java.util.Scanner;

public class NhapXuat {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nhap ho ten: ");
        String hoTen = sc.nextLine();

        System.out.print("Nhap tuoi: ");
        int tuoi = sc.nextInt();

        System.out.print("Nhap diem: ");
        double diem = sc.nextDouble();

        System.out.println("Ho ten: " + hoTen);
        System.out.println("Tuoi: " + tuoi);
        System.out.println("Diem: " + diem);

        sc.close();
    }
}

Các phương thức nhập thường dùng của Scanner:

Phương thứcChức năng
nextLine()Đọc cả dòng (chuỗi)
next()Đọc một từ (không chứa khoảng trắng)
nextInt()Đọc số nguyên
nextLong()Đọc số nguyên dài
nextFloat()Đọc số thực float
nextDouble()Đọc số thực double
nextBoolean()Đọc giá trị boolean

Lưu ý: Khi gặp lỗi "trôi lệnh" (bỏ qua lệnh nextLine sau nextInt), cần gọi thêm sc.nextLine() để xóa bộ đệm dòng.

PHẦN BÀI TẬP (4 MỨC ĐỘ)

Bài tập được chia thành 4 mức từ dễ đến khó. Sinh viên nên làm tuần tự từ mức 1 đến mức 4. Mỗi bài đều có lời giải ẩn trong nút "Xem lời giải".

🟢 MỨC 1 – NHẬN BIẾT (Dễ)

Mục tiêu: Ghi nhớ cú pháp, kiểu dữ liệu, lệnh in cơ bản.

Trắc nghiệm

  1. Kiểu dữ liệu nào dùng để lưu số nguyên?
    A. double   B. int   C. String   D. boolean
  2. Lệnh nào in ra màn hình và xuống dòng?
    A. System.out.print()   B. System.out.println()
    C. System.in.read()   D. System.out.write()
  3. Từ khóa nào khai báo hằng số?
    A. static   B. const   C. final   D. var
Xem đáp án
  1. B – int
  2. B – System.out.println()
  3. C – final

Bài tập lập trình

Bài 1.1. Viết chương trình in ra màn hình 2 dòng:

Bài 1.3. Cho a = 10, b = 3 (khai báo trực tiếp trong code). Tính và in tổng, hiệu, tích, thương nguyên, chia dư của a và b.

Xem lời giải 
public class Bai1_3 {
    public static void main(String[] args) {
        int a = 10, b = 3;
        System.out.println("Tong     = " + (a + b));   // 13

🟡 MỨC 2 – THÔNG HIỂU (Trung bình)

Mục tiêu: Hiểu cách nhập/xuất, ép kiểu, sử dụng toán tử.

Trắc nghiệm

  1. Với int a = 7, b = 2; thì a / b cho kết quả:
    A. 3.5   B. 3   C. 4   D. 1
  2. Phương thức nào của Scanner đọc cả dòng văn bản?
    A. next()   B. nextLine()   C. nextInt()   D. nextDouble()
  3. Ép kiểu (int) 9.99 cho kết quả:
    A. 9   B. 10   C. 9.99   D. Lỗi
Xem đáp án
  1. B – 3 (chia nguyên)
  2. B – nextLine()
  3. A – 9 (cắt phần lẻ)

Bài tập lập trình

Bài 2.1. Nhập vào hai số nguyên a, b. In ra tổng, hiệu, tích, thương (thương lấy phần thập phân, làm tròn 2 chữ số).

Xem lời giải 
import java.util.Scanner;

public class Bai2_1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap a: ");
        int a = sc.nextInt();
        System.out.print("Nhap b: ");
        int b = sc.nextInt();

        System.out.println("Tong  = " + (a + b));
        System.out.println("Hieu  = " + (a - b));
        System.out.println("Tich  = " + (a * b));
        if (b != 0) {
            System.out.printf("Thuong = %.2f%n", (double) a / b);
        } else {
            System.out.println("Khong the chia cho 0!");
        }
        sc.close();
    }
}

Bài 2.2. Nhập chiều dài d và chiều rộng r (số thực). Tính chu vi và diện tích hình chữ nhật.

Xem lời giải 
import java.util.Scanner;

public class Bai2_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap chieu dai: ");
        double d = sc.nextDouble();
        System.out.print("Nhap chieu rong: ");
        double r = sc.nextDouble();

        double chuVi = 2 * (d + r);
        double dienTich = d * r;

        System.out.printf("Chu vi    = %.2f%n", chuVi);
        System.out.printf("Dien tich = %.2f%n", dienTich);
        sc.close();
    }
}

Bài 2.3. Nhập một số nguyên n, kiểm tra và in ra n là số chẵn hay số lẻ.

Xem lời giải 
import java.util.Scanner;

public class Bai2_3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();

        if (n % 2 == 0) {
            System.out.println(n + " la so chan");
        } else {
            System.out.println(n + " la so le");
        }
        sc.close();
    }
}

🟠 MỨC 3 – VẬN DỤNG (Khó)

Mục tiêu: Kết hợp nhiều khái niệm, xử lý công thức, định dạng output.

Trắc nghiệm

  1. Cho int a = 5; int b = a++; Sau khi thực hiện, giá trị a và b là:
    A. a = 5, b = 5   B. a = 6, b = 6   C. a = 6, b = 5   D. a = 5, b = 6
  2. Kết quả của System.out.printf("%.2f", 3.14159) là:
    A. 3.14   B. 3.14159   C. 3.142   D. 3.1
  3. Biểu thức 10 + 5 * 2 cho kết quả:
    A. 30   B. 20   C. 25   D. 15
Xem đáp án
  1. C – a = 6, b = 5 (tăng sau)
  2. A – 3.14 (2 chữ số sau dấu phẩy)
  3. B – 20 (nhân trước, cộng sau)

🔴 MỨC 4 – VẬN DỤNG CAO (Rất khó)

Mục tiêu: Tổng hợp kiến thức, giải quyết bài toán phức tạp, tối ưu cách viết.

Trắc nghiệm

  1. Đoạn code sau in ra gì? 
    int a = 5;
int b = ++a + a++;
System.out.println("a = " + a + ", b = " + b);
    A. a = 7, b = 12   B. a = 7, b = 13   C. a = 6, b = 12   D. a = 6, b = 11
  2. Cho int x = 10; Biểu thức (x > 5) && (x < 20) ? "OK" : "FAIL" trả về:
    A. "OK"   B. "FAIL"   C. true   D. Lỗi
  3. Để in số thực 8.456 với đúng 2 chữ số sau dấu phẩy, dùng:
    A. %f   B. %.1f   C. %.2f   D. %d
Xem đáp án
  1. B – a = 7, b = 13. Giải thích: ++a tăng a lên 6 rồi trả về 6; a++ trả về 6 rồi tăng a lên 7; vậy b = 6 + 6 = 12? Thực tế: ++a → a=6, trả 6; a++ → trả 6, a=7; b = 6+6 = 12; kết quả đúng là a=7, b=12 → đáp án A. (Lưu ý: thứ tự đánh giá biểu thức có thể gây nhầm lẫn – nên tránh viết code kiểu này.)
  2. A – "OK"
  3. C – %.2f

Bài tập lập trình

Bài 4.1. Nhập hai số nguyên a, b. Dùng toán tử ba ngôi (không dùng if) để in ra số lớn hơn. Sau đó mở rộng: nhập 3 số, tìm số lớn nhất chỉ bằng toán tử ba ngôi.

Xem lời giải 
import java.util.Scanner;

public class Bai4_1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nhap a: ");
        int a = sc.nextInt();
        System.out.print("Nhap b: ");
        int b = sc.nextInt();
        System.out.print("Nhap c: ");
        int c = sc.nextInt();

        // Tìm max 2 số
        int max2 = (a > b) ? a : b;
        System.out.println("Max(a,b) = " + max2);

        // Tìm max 3 số chỉ dùng ternary
        int max3 = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
        System.out.println("Max(a,b,c) = " + max3);

        sc.close();
    }
}

Bài 4.2. Nhập số nguyên dương n. Tính tổng S = 1 + 2 + ... + n (dùng vòng lặp for). In kết quả. Sau đó kiểm tra lại bằng công thức n*(n+1)/2 xem có khớp không.

Xem lời giải 
import java.util.Scanner;

public class Bai4_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();

        int tong = 0;
        for (int i = 1; i <= n; i++) {
            tong += i;
        }

        int congThuc = n * (n + 1) / 2;

        System.out.println("Tong (vong lap) = " + tong);
        System.out.println("Tong (cong thuc) = " + congThuc);
        System.out.println("Khop? " + (tong == congThuc));

        sc.close();
    }
}

Bài 4.3. Bài tổng hợp: Nhập họ tên, năm sinh, điểm 3 môn. Tính tuổi (năm hiện tại 2026), điểm trung bình. In báo cáo theo định dạng:

===== BAO CAO =====
Ho ten   : Nguyen Van A
Tuoi     : 20
Diem TB  : 8.50
Ket qua  : DAT
===================

Biết rằng điểm TB >= 5.0 là ĐẠT, ngược lại là KHÔNG ĐẠT. Dùng toán tử ba ngôi để xếp loại.

Xem lời giải 
import java.util.Scanner;

public class Bai4_3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Nhap ho ten: ");
        String hoTen = sc.nextLine();

        System.out.print("Nhap nam sinh: ");
        int namSinh = sc.nextInt();

        System.out.print("Diem Toan: ");
        double toan = sc.nextDouble();
        System.out.print("Diem Ly: ");
        double ly = sc.nextDouble();
        System.out.print("Diem Hoa: ");
        double hoa = sc.nextDouble();

        final int NAM_HIEN_TAI = 2026;
        int tuoi = NAM_HIEN_TAI - namSinh;
        double diemTB = (toan + ly + hoa) / 3;
        String ketQua = (diemTB >= 5.0) ? "DAT" : "KHONG DAT";

        System.out.println("===== BAO CAO =====");
        System.out.printf("Ho ten   : %s%n", hoTen);
        System.out.printf("Tuoi     : %d%n", tuoi);
        System.out.printf("Diem TB  : %.2f%n", diemTB);
        System.out.printf("Ket qua  : %s%n", ketQua);
        System.out.println("===================");

        sc.close();
    }
}
