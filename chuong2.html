Mục tiêu chương

PHẦN LÝ THUYẾT

2.1. Biến trong Java – Nhìn sâu hơn

2.1.1. Khái niệm và cú pháp khai báo

Biến là một vùng nhớ có tên dùng để lưu trữ dữ liệu. Mỗi biến trong Java đều có kiểu dữ liệu xác định, tên và giá trị. Cú pháp tổng quát: 

[kieuDuLieu] tenBien;              // Khai báo
[kieuDuLieu] tenBien = giaTri;     // Khai báo và khởi tạo
[kieuDuLieu] a = 1, b = 2, c;      // Khai báo nhiều biến cùng kiểu

Trong Java, biến bắt buộc phải có kiểu dữ liệu khi khai báo (trừ khi dùng var từ Java 10 – trình biên dịch sẽ tự suy luận kiểu).

2.1.2. Phân loại biến theo phạm vi (Scope)

Java có 3 loại biến chính dựa trên vị trí khai báo:

Loại biến Vị trí khai báo Giá trị mặc định Phạm vi sử dụng
Biến cục bộ (local) Bên trong phương thức / khối lệnh Không có – phải khởi tạo trước khi dùng Chỉ trong phương thức / khối chứa nó
Biến thực thể (instance) Bên trong lớp, ngoài phương thức (không có static) Có (0, false, null…) Trong suốt đối tượng, truy cập qua this.
Biến tĩnh (static) Bên trong lớp, có từ khóa static Có (0, false, null…) Dùng chung cho mọi đối tượng của lớp

Ví dụ minh họa 3 loại biến:

public class SinhVien {
    static int soLuong = 0;      // biến tĩnh
    String hoTen;                // biến thực thể
    int tuoi;                    // biến thực thể

    public void hienThi() {
        int diem = 10;           // biến cục bộ
        System.out.println(diem);
    }
}

2.1.3. Giá trị mặc định của biến

Kiểu dữ liệu Giá trị mặc định
byte, short, int, long0
float, double0.0
char'\u0000' (ký tự null)
booleanfalse
Kiểu tham chiếu (String, mảng, lớp…)null

Lưu ý: biến cục bộ không có giá trị mặc định. Nếu dùng trước khi khởi tạo, chương trình sẽ báo lỗi biên dịch "variable might not have been initialized".

2.1.4. Từ khóa var (Java 10+)

Từ Java 10, có thể dùng var để trình biên dịch tự suy luận kiểu dựa trên giá trị khởi tạo. Biến var vẫn là kiểu tĩnh (không đổi kiểu được sau khi gán). 

var tuoi = 20;               // int
var diem = 8.5;              // double
var ten = "Nguyen Van A";    // String
var ds = new ArrayList<String>();   // ArrayList<String>

// tuoi = "hai muoi";  // LỖI: không thể gán String cho biến int

Lưu ý: var chỉ dùng được cho biến cục bộ, không dùng cho thuộc tính lớp hay tham số phương thức, và phải khởi tạo ngay khi khai báo.

2.2. Hằng số và từ khóa final

Hằng là biến có giá trị không thể thay đổi sau khi gán. Trong Java, dùng từ khóa final để khai báo hằng. Theo quy ước, tên hằng viết hoa toàn bộ, các từ cách nhau bởi dấu gạch dưới _. 

final double PI = 3.14159;
final int MAX_SINH_VIEN = 100;
final String TEN_TRUONG = "PTIT";

// PI = 3.14;   // LỖI: không thể gán lại giá trị cho biến final

Lưu ý: với biến tham chiếu final, bản thân tham chiếu không đổi, nhưng nội dung bên trong đối tượng vẫn có thể thay đổi (trừ khi đối tượng là bất biến). 

final int[] arr = {1, 2, 3};
arr[0] = 99;               // HỢP LỆ: thay đổi phần tử
// arr = new int[]{4,5};   // LỖI: không thể trỏ sang mảng khác

2.3. Kiểu dữ liệu nguyên thủy (Primitive Types)

2.3.1. Bảng tổng hợp 8 kiểu nguyên thủy

Nhóm Kiểu Kích thước Miền giá trị Lớp bao tương ứng
Số nguyên byte1 byte-128 đến 127Byte
short2 byte-32.768 đến 32.767Short
int4 byte-2^31 đến 2^31 - 1Integer
long8 byte-2^63 đến 2^63 - 1Long
Số thực float4 byte~ ±3.4e-38 đến ±3.4e+38Float
double8 byte~ ±1.7e-308 đến ±1.7e+308Double
Ký tựchar2 byte 0 đến 65.535 (Unicode)Character

2.3.2. Lưu ý khi dùng từng kiểu

  • int là kiểu số nguyên được dùng phổ biến nhất.
  • Khi gán giá trị vượt miền của int cho long, phải thêm hậu tố L: long l = 10000000000L;
  • Khi gán giá trị thực cho float, phải thêm hậu tố f: float f = 3.14f; – nếu không, Java hiểu là double và báo lỗi.
  • char lưu một ký tự Unicode trong dấu nháy đơn: 'A', '9', '\n', '\u0041'.
  • boolean chỉ có hai giá trị true / false (không dùng 0/1 như C).

2.3.3. Ví dụ khai báo đúng / sai

int a = 10;                 // OK
long b = 10000000000L;      // OK (có L)
float f = 3.14f;            // OK (có f)
char c = 'J';               // OK
boolean ok = true;          // OK

// long b = 10000000000;    // LỖI: vượt miền int
// float f = 3.14;          // LỖI: 3.14 mặc định là double
// char c = "J";            // LỖI: nháy kép là String
// boolean b2 = 1;          // LỖI: không dùng 0/1

2.4. Kiểu dữ liệu tham chiếu và lớp bao (Wrapper Class)

2.4.1. Kiểu tham chiếu

Kiểu tham chiếu lưu địa chỉ (tham chiếu) tới đối tượng trong bộ nhớ heap, không lưu trực tiếp giá trị như kiểu nguyên thủy. Các kiểu tham chiếu phổ biến: String, mảng, lớp, interface, enum…

2.4.2. Lớp bao (Wrapper Class)

Mỗi kiểu nguyên thủy đều có một lớp bao tương ứng trong gói java.lang. Lớp bao cung cấp thêm các phương thức tiện ích và cho phép dùng kiểu nguyên thủy trong các cấu trúc chỉ nhận đối tượng (như ArrayList, HashMap…).

Kiểu nguyên thủyLớp baoVí dụ
intIntegerInteger x = 10;
doubleDoubleDouble d = 3.14;
charCharacterCharacter c = 'A';
booleanBooleanBoolean b = true;

2.4.3. Autoboxing và Unboxing

  • Autoboxing: tự động chuyển từ kiểu nguyên thủy → lớp bao.
  • Unboxing: tự động chuyển từ lớp bao → kiểu nguyên thủy.
Integer a = 100;         // autoboxing: int → Integer
int b = a;               // unboxing: Integer → int

ArrayList<Integer> ds = new ArrayList<>();
ds.add(5);               // autoboxing: 5 → Integer
int x = ds.get(0);       // unboxing

Cảnh báo: khi unboxing một đối tượng null sẽ gây NullPointerException. Ví dụ: Integer z = null; int t = z; → lỗi.

2.5. Kiểu String và các phương thức phổ biến

2.5.1. Đặc điểm của String

  • String là lớp bất biến (immutable) – một khi tạo ra, nội dung không thể thay đổi. Mọi "thay đổi" thực chất là tạo đối tượng mới.
  • Chuỗi ký tự được đặt trong dấu nháy kép "...".
  • Java có String Pool: các chuỗi literal giống nhau được chia sẻ cùng một đối tượng.

2.5.2. So sánh chuỗi: == và equals()

String a = "Java";
String b = "Java";
String c = new String("Java");

System.out.println(a == b);            // true  (cùng tham chiếu trong pool)
System.out.println(a == c);            // false (c là đối tượng mới)
System.out.println(a.equals(c));       // true  (so sánh nội dung)
System.out.println(a.equalsIgnoreCase("JAVA")); // true

Quy tắc: luôn dùng equals() để so sánh nội dung chuỗi, không dùng ==.

2.5.4. Nối chuỗi và StringBuilder

Phép + khi dùng với chuỗi sẽ tự động chuyển giá trị các kiểu khác sang chuỗi. Tuy nhiên, khi cần nối nhiều chuỗi trong vòng lặp, nên dùng StringBuilder để tránh tạo quá nhiều đối tượng trung gian. 

// Cách 1: nối bằng +
String s = "";
for (int i = 0; i < 1000; i++) {
    s += i;             // Tạo 1000 đối tượng mới – kém hiệu quả
}

// Cách 2: dùng StringBuilder – hiệu quả hơn
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String ketQua = sb.toString();

2.6. Chuyển đổi kiểu dữ liệu (Type Conversion)

2.6.1. Ép kiểu ngầm định (Widening)

Từ kiểu nhỏ → kiểu lớn, Java tự động thực hiện. Lưu ý: khi chuyển từ số nguyên sang float/double, giá trị có thể bị mất độ chính xác nếu số nguyên có nhiều chữ số (ví dụ int → float).

int i = 10;
double d = i;         // int → double: 10.0
long l = i;           // int → long
float f = i;          // int → float

Thứ tự mở rộng hợp lệ:

byte → short → int → long → float → double
                char → int

2.6.2. Ép kiểu tường minh (Narrowing)

Từ kiểu lớn → kiểu nhỏ, có thể mất dữ liệu, phải ép bằng cú pháp (kieuDuLieu).

double d = 9.7;
int i = (int) d;      // i = 9 (mất phần lẻ)

long l = 1000L;
byte b = (byte) l;    // ép về byte

int x = 130;
byte y = (byte) x;    // y = -126 (tràn số)

2.6.3. Chuyển đổi giữa chuỗi và số

Chuyển đổiCách làmVí dụ
String → intInteger.parseInt(s)Integer.parseInt("123") → 123
String → longLong.parseLong(s)Long.parseLong("1000") → 1000
String → doubleDouble.parseDouble(s)Double.parseDouble("3.14") → 3.14
String → floatFloat.parseFloat(s)Float.parseFloat("1.5") → 1.5
int → StringString.valueOf(n) hoặc "" + nString.valueOf(100) → "100"

Lưu ý: nếu chuỗi không phải số hợp lệ, các phương thức parseXXX sẽ ném ra NumberFormatException. Cần dùng try-catch để xử lý. 

try {
    int n = Integer.parseInt("abc");   // Lỗi
} catch (NumberFormatException e) {
    System.out.println("Chuoi khong phai so!");
}

2.7. Quy ước và thực hành tốt khi dùng biến

2.7.1. Quy tắc đặt tên biến

  • Bắt đầu bằng chữ cái, _ hoặc $; không bắt đầu bằng chữ số.
  • Không chứa khoảng trắng, không dùng ký tự đặc biệt (trừ _, $).
  • Không trùng với từ khóa (class, int, public…).
  • Java phân biệt hoa/thường (ten khác Ten).
  • Đặt tên theo camelCase và có ý nghĩa: hoTen, diemTrungBinh…

2.7.2. Một số thực hành tốt

  • Ưu tiên khai báo biến gần nơi sử dụng, có phạm vi nhỏ nhất có thể.
  • Khởi tạo ngay khi khai báo nếu đã biết giá trị.
  • Dùng final cho các giá trị không đổi để tránh gán nhầm.
  • Không dùng == để so sánh chuỗi – dùng equals().
  • Đặt tên hằng bằng chữ HOA có dấu gạch dưới.
  • Tránh "magic number" – thay bằng hằng số có tên gợi nhớ.
// Kém rõ ràng
if (diem >= 5.0) { ... }

// Tốt hơn
final double DIEM_DAT = 5.0;
if (diem >= DIEM_DAT) { ... }

2.8. Ví dụ tổng hợp

Chương trình minh họa khai báo biến, hằng, ép kiểu, xử lý chuỗi và wrapper class:

import java.util.Scanner;

public class BienVaKieuDuLieu {
    static final double PI = 3.14159;
    static int soLanChay = 0;

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        soLanChay++;

        // 1. Nhập dữ liệu
        System.out.print("Nhap ho ten: ");
        String hoTen = sc.nextLine();

        System.out.print("Nhap tuoi: ");
        int tuoi = sc.nextInt();

        System.out.print("Nhap diem trung binh: ");
        double diem = sc.nextDouble();

        // 2. Ép kiểu
        int diemNguyen = (int) diem;
        long danSo = 8_000_000_000L;
        Integer tuoiWrap = tuoi;             // autoboxing
        int tuoiInt = tuoiWrap;              // unboxing

        // 3. Xử lý chuỗi
        String tenHoa = hoTen.toUpperCase();
        String tenThuong = hoTen.toLowerCase();
        boolean hopLe = hoTen.length() > 0 && !hoTen.trim().isEmpty();

        // 4. Tính toán
        double chuVi = 2 * PI * 5;
        double thuong = (double) tuoi / 3;

        // 5. Xuất kết quả
        System.out.println("--- KET QUA ---");
        System.out.println("Ho ten (hoa): " + tenHoa);
        System.out.println("Ho ten (thuong): " + tenThuong);
        System.out.println("Ten hop le: " + hopLe);
        System.out.println("Tuoi: " + tuoiInt);
        System.out.println("Diem (double): " + diem);
        System.out.println("Diem (int): " + diemNguyen);
        System.out.println("Dan so: " + danSo);
        System.out.println("Thuong tuoi/3: " + thuong);
        System.out.printf("Chu vi hinh tron r=5: %.2f%n", chuVi);
        System.out.println("So lan chay: " + soLanChay);

        sc.close();
    }
}

PHẦN BÀI TẬP (4 MỨC ĐỘ)

Bài tập được chia thành 4 mức từ dễ đến khó. Sinh viên nên làm tuần tự từ mức 1 đến mức 4. Mỗi bài đều có lời giải ẩn trong nút "Xem lời giải".

🟢 MỨC 1 – NHẬN BIẾT (Dễ)

Mục tiêu: Ghi nhớ khái niệm biến, kiểu dữ liệu, hằng số, giá trị mặc định.

Trắc nghiệm

  1. Biến cục bộ (local variable) trong Java có giá trị mặc định là gì?
    A. 0   B. null   C. false   D. Không có giá trị mặc định
  2. Khai báo nào sau đây hợp lệ?
    A. float f = 3.14;   B. long l = 10000000000;
    C. float f = 3.14f;   D. char c = "A";
  3. Từ khóa final dùng để:
    A. Khai báo hằng số   B. Khai báo biến toàn cục
    C. Kết thúc chương trình   D. Khai báo lớp kế thừa
Xem đáp án
  1. D – Biến cục bộ không có giá trị mặc định
  2. C – Phải có hậu tố f cho float
  3. A – Khai báo hằng số

Bài tập lập trình

Bài 1.1. Khai báo các biến thuộc 8 kiểu nguyên thủy với giá trị tùy ý, sau đó in ra màn hình theo mẫu: Kieu du lieu X co gia tri = ...

Xem lời giải 
public class Bai1_1 {
    public static void main(String[] args) {
        byte b = 100;
        short s = 1000;
        int i = 2024;
        long l = 10000000000L;
        float f = 3.14f;
        double d = 3.14159;
        char c = 'J';
        boolean ok = true;

        System.out.println("byte    = " + b);
        System.out.println("short   = " + s);
        System.out.println("int     = " + i);
        System.out.println("long    = " + l);
        System.out.println("float   = " + f);
        System.out.println("double  = " + d);
        System.out.println("char    = " + c);
        System.out.println("boolean = " + ok);
    }
}

Bài 1.2. Khai báo hằng PI = 3.14159 và hằng R = 5.0. Tính và in chu vi, diện tích hình tròn (làm tròn 2 chữ số).

Xem lời giải 
public class Bai1_2 {
    public static void main(String[] args) {
        final double PI = 3.14159;
        final double R  = 5.0;

        double chuVi    = 2 * PI * R;
        double dienTich = PI * R * R;

        System.out.printf("Chu vi     = %.2f%n", chuVi);
        System.out.printf("Dien tich  = %.2f%n", dienTich);
    }
}

🟡 MỨC 2 – THÔNG HIỂU (Trung bình)

Mục tiêu: Hiểu ép kiểu, wrapper class, các phương thức String cơ bản.

Trắc nghiệm

  1. Cho double d = 9.99; int i = (int) d; Giá trị của i là:
    A. 9   B. 10   C. 9.99   D. Lỗi biên dịch
  2. Phương thức nào dùng để lấy độ dài của chuỗi?
    A. size()   B. length()   C. count()   D. getLength()
  3. Cơ chế tự động chuyển từ int sang Integer gọi là:
    A. Casting   B. Unboxing   C. Autoboxing   D. Parsing
Xem đáp án
  1. A – 9 (ép kiểu tường minh cắt phần lẻ)
  2. B – length()
  3. C – Autoboxing

Bài tập lập trình

Bài 2.1. Khai báo double d = 9.99;, ép sang int và in cả hai giá trị. Sau đó khai báo int x = 130;, ép sang byte và in ra để thấy hiện tượng tràn số.

Xem lời giải 
public class Bai2_1 {
    public static void main(String[] args) {
        double d = 9.99;
        int i = (int) d;
        System.out.println("double d = " + d);
        System.out.println("int i    = " + i);      // 9 - mất phần lẻ

        int x = 130;
        byte y = (byte) x;
        System.out.println("int x  = " + x);
        System.out.println("byte y = " + y);        // -126 - tràn số
    }
}

Bài 2.2. Nhập vào một chuỗi họ tên. In ra: độ dài chuỗi, chuỗi in hoa, chuỗi in thường, ký tự đầu, ký tự cuối, chuỗi sau khi xóa khoảng trắng hai đầu.

Xem lời giải 
import java.util.Scanner;

Bài 2.3. Khai báo Integer a = 100; (autoboxing), gán sang int b (unboxing). In ra tổng a + b. In giá trị lớn nhất / nhỏ nhất của Integer.

Xem lời giải 
public class Bai2_3 {
    public static void main(String[] args) {
        Integer a = 100;        // autoboxing
        int b = a;              // unboxing

        System.out.println("a = " + a);
        System.out.println("b = " + b);
        System.out.println("a + b = " + (a + b));
        System.out.println("MAX = " + Integer.MAX_VALUE);
        System.out.println("MIN = " + Integer.MIN_VALUE);
    }
}

🟠 MỨC 3 – VẬN DỤNG (Khó)

Mục tiêu: So sánh chuỗi đúng cách, parse số, xử lý ngoại lệ, static vs instance.

Trắc nghiệm

  1. Đoạn code sau in ra gì? 
    String a = "Java";
String b = new String("Java");
System.out.println(a == b);
System.out.println(a.equals(b));
    A. true / true   B. false / true   C. true / false   D. false / false
  2. Từ khóa static khi gắn với biến có ý nghĩa gì?
    A. Biến chỉ đọc   B. Biến dùng chung cho mọi đối tượng của lớp
    C. Biến cục bộ trong phương thức   D. Biến không thể khởi tạo
  3. Đoạn code sau gây ra lỗi gì? 
    Integer x = null;
int y = x;
    A. Lỗi biên dịch   B. NullPointerException
    C. NumberFormatException   D. Không lỗi, y = 0
Xem đáp án
  1. B – == so sánh tham chiếu (false), equals() so sánh nội dung (true)
  2. B – Biến tĩnh dùng chung cho mọi đối tượng
  3. B – Unboxing null gây NullPointerException

Bài tập lập trình

Bài 3.1. Khai báo String a = "Hello";, String b = "Hello";, String c = new String("Hello");. In kết quả so sánh a == b, a == c, a.equals(c) và giải thích bằng chú thích trong code.

Xem lời giải 
public class Bai3_1 {
    public static void main(String[] args) {
        String a = "Hello";
        String b = "Hello";
        String c = new String("Hello");

        // a và b cùng trỏ tới literal trong String Pool
        System.out.println("a == b        : " + (a == b));   // true

        // c là đối tượng mới trên heap → tham chiếu khác
        System.out.println("a == c        : " + (a == c));   // false

        // equals() so sánh nội dung
        System.out.println("a.equals(c)   : " + a.equals(c)); // true
    }
}

Bài 3.2. Nhập vào hai chuỗi số (ví dụ "12" và "8"). Chuyển sang số nguyên bằng Integer.parseInt(), in tổng, hiệu, tích, thương. Thử nhập chuỗi không hợp lệ như "abc" để thấy NumberFormatException và xử lý bằng try-catch.

Xem lời giải 
import java.util.Scanner;

public class Bai3_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap chuoi so 1: ");
        String s1 = sc.nextLine();
        System.out.print("Nhap chuoi so 2: ");
        String s2 = sc.nextLine();

        try {
            int a = Integer.parseInt(s1);
            int b = Integer.parseInt(s2);

            System.out.println("Tong  = " + (a + b));
            System.out.println("Hieu  = " + (a - b));
            System.out.println("Tich  = " + (a * b));

            if (b != 0) {
                System.out.println("Thuong = " + ((double) a / b));
            } else {
                System.out.println("Khong the chia cho 0");
            }
        } catch (NumberFormatException e) {
            System.out.println("Chuoi nhap vao khong phai so hop le!");
        }
        sc.close();
    }
}

Bài 3.3. Tạo lớp Dem có biến static int soLuong và biến int maSo. Trong hàm tạo, tăng soLuong và gán maSo = soLuong. Tạo 3 đối tượng và in ra soLuong, maSo của từng đối tượng để thấy sự khác biệt giữa biến static và biến instance.

Xem lời giải 
public class Bai3_3 {
    static class Dem {
        static int soLuong = 0;   // dùng chung
        int maSo;                 // riêng từng đối tượng

        Dem() {
            soLuong++;
            maSo = soLuong;
        }
    }

    public static void main(String[] args) {
        Dem d1 = new Dem();
        Dem d2 = new Dem();
        Dem d3 = new Dem();

        System.out.println("d1: maSo = " + d1.maSo + ", soLuong = " + Dem.soLuong);
        System.out.println("d2: maSo = " + d2.maSo + ", soLuong = " + Dem.soLuong);
        System.out.println("d3: maSo = " + d3.maSo + ", soLuong = " + Dem.soLuong);
        // soLuong = 3 cho cả 3, maSo lần lượt 1, 2, 3
    }
}

🔴 MỨC 4 – VẬN DỤNG CAO (Rất khó)

Mục tiêu: Tổng hợp String, StringBuilder, var, xử lý chuỗi phức tạp.

Trắc nghiệm

  1. Từ khóa var (Java 10+) không dùng được trong trường hợp nào?
    A. Biến cục bộ trong phương thức   B. Thuộc tính của lớp
    C. Biến trong khối lệnh   D. Biến trong vòng lặp for
  2. Đoạn code sau in ra gì? 
    String s = "Java";
s.toUpperCase();
System.out.println(s);
    A. JAVA   B. Java   C. java   D. Lỗi
  3. Để nối nhiều chuỗi trong vòng lặp hiệu quả, nên dùng:
    A. Phép +   B. String.concat()
    C. StringBuilder   D. String.format()
Xem đáp án
  1. B – var chỉ dùng cho biến cục bộ
  2. B – String bất biến, toUpperCase() trả về chuỗi mới chứ không thay đổi s
  3. C – StringBuilder

Bài tập lập trình

Bài 4.1. Nhập một chuỗi, đếm xem chuỗi có bao nhiêu ký tự là nguyên âm (a, e, i, o, u – không phân biệt hoa/thường).

Xem lời giải 
import java.util.Scanner;

public class Bai4_1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap chuoi: ");
        String s = sc.nextLine().toLowerCase();

        int dem = 0;
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') {
                dem++;
            }
        }

        System.out.println("So nguyen am = " + dem);
        sc.close();
    }
}

Bài 4.2. Nhập một chuỗi họ tên, in ra tên (phần sau khoảng trắng cuối cùng) và họ (phần trước khoảng trắng đầu tiên).

Xem lời giải 
import java.util.Scanner;

public class Bai4_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap ho ten: ");
        String hoTen = sc.nextLine().trim();

        int viTriCuoi = hoTen.lastIndexOf(' ');
        int viTriDau  = hoTen.indexOf(' ');

        if (viTriCuoi == -1) {
            System.out.println("Chi co mot tu: " + hoTen);
        } else {
            String ho  = hoTen.substring(0, viTriDau);
            String ten = hoTen.substring(viTriCuoi + 1);
            System.out.println("Ho  : " + ho);
            System.out.println("Ten : " + ten);
        }
        sc.close();
    }
}

Bài 4.3. Bài tổng hợp: Dùng var để khai báo biến cục bộ. Dùng StringBuilder để nối các số từ 1 đến 10 thành chuỗi "1,2,3,...,10". Sau đó tách chuỗi này theo dấu phẩy, chuyển từng phần tử sang số nguyên và tính tổng.

Xem lời giải 
public class Bai4_3 {
    public static void main(String[] args) {
        // 1. Dùng var + StringBuilder nối chuỗi
        var sb = new StringBuilder();
        for (int i = 1; i <= 10; i++) {
            if (i > 1) sb.append(",");
            sb.append(i);
        }
        var chuoi = sb.toString();
        System.out.println("Chuoi: " + chuoi);

        // 2. Tách chuỗi theo dấu phẩy
        var parts = chuoi.split(",");

        // 3. Chuyển sang số và tính tổng
        int tong = 0;
        for (var p : parts) {
            tong += Integer.parseInt(p);
        }
        System.out.println("Tong = " + tong);   // 55
    }
}

Bài 4.4. Bài thách thức: Viết chương trình nhập vào một câu văn. In ra câu văn đó với mỗi từ được viết hoa chữ cái đầu (ví dụ: "hello world java" → "Hello World Java"). Dùng split() và StringBuilder.

Xem lời giải 
import java.util.Scanner;

public class Bai4_4 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap cau: ");
        String cau = sc.nextLine().trim().toLowerCase();

        var sb = new StringBuilder();
        var tu = cau.split("\\s+");

        for (int i = 0; i < tu.length; i++) {
            if (tu[i].length() > 0) {
                sb.append(Character.toUpperCase(tu[i].charAt(0)));
                sb.append(tu[i].substring(1));
            }
            if (i < tu.length - 1) sb.append(" ");
        }

        System.out.println("Ket qua: " + sb);
        sc.close();
    }
}

Tổng kết chương 2

  • Biến có 3 loại theo phạm vi: cục bộ, thực thể, tĩnh; biến cục bộ không có giá trị mặc định.
  • Hằng số dùng final, tên viết HOA có dấu gạch dưới.
  • Java có 8 kiểu nguyên thủy, mỗi kiểu có lớp bao tương ứng trong java.lang.
  • Autoboxing / unboxing giúp chuyển đổi tự động giữa primitive và wrapper.
  • String là bất biến; so sánh nội dung bằng equals(), không dùng ==.
  • Nối nhiều chuỗi nên dùng StringBuilder để tăng hiệu năng.
  • Ép kiểu ngầm định an toàn, ép kiểu tường minh có thể mất dữ liệu.
  • Chuyển chuỗi ↔ số dùng parseXXX / String.valueOf(); cần xử lý NumberFormatException.
  • Dùng var (Java 10+) cho biến cục bộ khi kiểu đã rõ ràng.
