CHƯƠNG 4: MẢNG TRONG JAVA

Mục tiêu chương

  • Hiểu khái niệm mảng, đặc điểm của mảng trong Java (kích thước cố định, chỉ số từ 0).
  • Biết cách khai báo, khởi tạo mảng theo nhiều cách khác nhau.
  • Phân biệt mảng một chiều, mảng hai chiều và mảng răng cưa (jagged array).
  • Sử dụng thành thạo vòng lặp for và for-each để duyệt mảng.
  • Nắm được các thao tác cơ bản: tính tổng, tìm max/min, đảo mảng, tìm kiếm, sắp xếp.
  • Sử dụng lớp tiện ích java.util.Arrays và System.arraycopy().
  • Hiểu mối quan hệ giữa mảng và tham chiếu, tránh các lỗi thường gặp.
  • Biết cách truyền mảng vào phương thức và trả về mảng từ phương thức.

PHẦN LÝ THUYẾT

4.1. Mảng là gì? – Nhìn sâu hơn

4.1.1. Khái niệm và đặc điểm

Mảng (array) là một tập hợp các phần tử cùng kiểu dữ liệu được lưu trữ liên tiếp nhau trong bộ nhớ, và được truy cập thông qua chỉ số (index). Mảng trong Java là đối tượng (object) – được tạo bằng từ khóa new và có thuộc tính length.

  • Kích thước mảng cố định sau khi khởi tạo – không thể thay đổi.
  • Chỉ số bắt đầu từ 0 đến length - 1.
  • Các phần tử có cùng kiểu dữ liệu (nguyên thủy hoặc tham chiếu).
  • Truy cập phần tử có độ phức tạp O(1) – rất nhanh.
  • Mảng lưu tham chiếu tới vùng nhớ trên heap, biến mảng chỉ giữ địa chỉ.

Lưu ý: truy cập chỉ số ngoài phạm vi [0, length - 1] sẽ gây ra ngoại lệ ArrayIndexOutOfBoundsException.

4.1.2. Cú pháp khai báo

Có hai cách viết tương đương (Java ưu tiên cách 1):

// Cách 1: kiểu[] tenMang  (khuyến nghị)
int[] diem;
String[] hoTen;

// Cách 2: kiểu tenMang[]  (kiểu C/C++, vẫn hợp lệ)
int diem[];
String hoTen[];

Khai báo chỉ tạo biến tham chiếu, chưa cấp phát vùng nhớ cho các phần tử. Muốn dùng phải khởi tạo bằng new hoặc gán trực tiếp bằng mảng literal.

4.1.3. Khởi tạo mảng

// 1. Khởi tạo với kích thước cho trước (phần tử nhận giá trị mặc định)
int[] a = new int[5];              // {0, 0, 0, 0, 0}
String[] ten = new String[3];      // {null, null, null}

// 2. Khởi tạo kèm giá trị (mảng literal)
int[] b = {1, 2, 3, 4, 5};
String[] mau = {"Đỏ", "Xanh", "Vàng"};

// 3. Khởi tạo bằng new + literal
int[] c = new int[]{10, 20, 30};

// 4. Khai báo trước, gán sau
int[] d;
d = new int[]{7, 8, 9};

Lưu ý: khi dùng {...} thì không được ghi kích thước trong []: new int[3]{1,2,3} là sai.

4.1.4. Giá trị mặc định của phần tử mảng

Kiểu phần tử Giá trị mặc định
byte, short, int, long0
float, double0.0
char'\u0000'
booleanfalse
Kiểu tham chiếu (String, Object…)null

Mảng vừa tạo bằng new luôn được gán giá trị mặc định theo kiểu tương ứng.

4.2. Truy cập và duyệt mảng

4.2.1. Truy cập phần tử theo chỉ số

int[] a = {10, 20, 30, 40, 50};

System.out.println(a[0]);     // 10
System.out.println(a[4]);     // 50
System.out.println(a.length); // 5

a[2] = 99;                     // Gán lại phần tử
// a[5] = 100;                 // LỖI: ArrayIndexOutOfBoundsException

4.2.2. Duyệt mảng bằng for cổ điển

int[] a = {1, 2, 3, 4, 5};

for (int i = 0; i < a.length; i++) {
    System.out.println("a[" + i + "] = " + a[i]);
}

Dùng for cổ điển khi cần biết chỉ số (để gán, đảo mảng, sắp xếp…).

4.2.3. Duyệt mảng bằng for-each

int[] a = {1, 2, 3, 4, 5};

for (int x : a) {
    System.out.println(x);
}

Lưu ý: for-each chỉ đọc phần tử, không gán lại được giá trị vào mảng. Nếu cần thay đổi phần tử phải dùng for cổ điển.

4.3. Các thao tác cơ bản trên mảng một chiều

4.3.1. Tính tổng, trung bình cộng

int[] a = {4, 8, 15, 16, 23, 42};
int tong = 0;
for (int x : a) tong += x;
double tb = (double) tong / a.length;

System.out.println("Tong = " + tong);  // 108
System.out.println("TB   = " + tb);    // 18.0

4.3.2. Tìm giá trị lớn nhất / nhỏ nhất

int[] a = {4, 8, 15, 16, 23, 42};
int max = a[0], min = a[0];

for (int i = 1; i < a.length; i++) {
    if (a[i] > max) max = a[i];
    if (a[i] < min) min = a[i];
}
System.out.println("Max = " + max + ", Min = " + min);

4.3.3. Đảo ngược mảng

int[] a = {1, 2, 3, 4, 5};

for (int i = 0, j = a.length - 1; i < j; i++, j--) {
    int tmp = a[i];
    a[i] = a[j];
    a[j] = tmp;
}
// a = {5, 4, 3, 2, 1}

4.3.4. Đếm số phần tử thỏa điều kiện

int[] a = {1, 2, 3, 4, 5, 6, 7, 8};
int demChan = 0;
for (int x : a) {
    if (x % 2 == 0) demChan++;
}
System.out.println("So phan tu chan = " + demChan); // 4

4.3.5. Tìm kiếm tuyến tính (Linear Search)

int[] a = {4, 8, 15, 16, 23, 42};
int canTim = 16;
int viTri = -1;

for (int i = 0; i < a.length; i++) {
    if (a[i] == canTim) {
        viTri = i;
        break;
    }
}
System.out.println("Tim thay tai vi tri: " + viTri); // 3

4.4. Mảng hai chiều

4.4.1. Khái niệm

Mảng hai chiều là mảng của các mảng – mỗi phần tử là một mảng một chiều. Dùng để biểu diễn ma trận, bảng số liệu, bàn cờ…

4.4.2. Khai báo và khởi tạo

// Cách 1: mảng đều (rectangular)
int[][] m = new int[3][4];             // 3 dòng, 4 cột

// Cách 2: literal
int[][] m2 = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

// Cách 3: mảng răng cưa (jagged) - mỗi dòng có số cột khác nhau
int[][] m3 = new int[3][];
m3[0] = new int[]{1, 2};
m3[1] = new int[]{3, 4, 5};
m3[2] = new int[]{6};

4.4.3. Truy cập và duyệt

int[][] m = {
    {1, 2, 3},
    {4, 5, 6}
};

System.out.println(m[0][1]);  // 2
System.out.println(m.length);     // 2 (số dòng)
System.out.println(m[0].length);  // 3 (số cột của dòng 0)

// Duyệt bằng 2 vòng for
for (int i = 0; i < m.length; i++) {
    for (int j = 0; j < m[i].length; j++) {
        System.out.print(m[i][j] + " ");
    }
    System.out.println();
}

// Duyệt bằng for-each lồng
for (int[] dong : m) {
    for (int x : dong) {
        System.out.print(x + " ");
    }
    System.out.println();
}

Lưu ý: với mảng răng cưa, không dùng m[0].length cho tất cả các dòng – phải dùng m[i].length.

4.5. Lớp tiện ích java.util.Arrays

Java cung cấp lớp Arrays với nhiều phương thức tĩnh hữu ích để làm việc với mảng. Cần import java.util.Arrays; trước khi dùng.

Phương thứcChức năngVí dụ
toString(arr)Chuyển mảng thành chuỗi để in Arrays.toString(a)
sort(arr)Sắp xếp tăng dần (tại chỗ) Arrays.sort(a)
sort(arr, from, to)Sắp xếp một đoạn Arrays.sort(a, 1, 4)
binarySearch(arr, key)Tìm kiếm nhị phân (mảng phải sắp xếp) Arrays.binarySearch(a, 5)
fill(arr, val)Gán tất cả phần tử bằng val Arrays.fill(a, 0)
copyOf(arr, n)Sao chép sang mảng mới kích thước n Arrays.copyOf(a, 10)
copyOfRange(arr, from, to)Sao chép đoạn Arrays.copyOfRange(a, 2, 5)
equals(a, b)So sánh nội dung hai mảng Arrays.equals(a, b)
deepToString(m)In mảng hai chiều Arrays.deepToString(m2d)

Ví dụ minh họa

import java.util.Arrays;

public class ViDuArrays {
    public static void main(String[] args) {
        int[] a = {5, 2, 8, 1, 9, 3};

        System.out.println("Ban dau: " + Arrays.toString(a));

        Arrays.sort(a);
        System.out.println("Sau sort: " + Arrays.toString(a));  // [1,2,3,5,8,9]

        int idx = Arrays.binarySearch(a, 5);
        System.out.println("Vi tri cua 5: " + idx);             // 3

        int[] b = Arrays.copyOf(a, 10);
        System.out.println("Sau copy: " + Arrays.toString(b));  // 10 phần tử

        Arrays.fill(b, 0);
        System.out.println("Sau fill: " + Arrays.toString(b));  // toàn 0
    }
}

Sao chép mảng bằng System.arraycopy()

int[] src = {1, 2, 3, 4, 5};
int[] dest = new int[5];

System.arraycopy(src, 0, dest, 0, src.length);
// dest = {1, 2, 3, 4, 5}

Cú pháp: System.arraycopy(mangNguon, viTriNguon, mangDich, viTriDich, soPhanTu).

4.6. Mảng và tham chiếu – Lỗi thường gặp

4.6.1. Gán mảng là gán tham chiếu

int[] a = {1, 2, 3};
int[] b = a;               // b trỏ CÙNG mảng với a

b[0] = 99;
System.out.println(a[0]);  // 99 – vì a và b cùng tham chiếu

Muốn sao chép thật sự (tạo mảng mới), phải dùng Arrays.copyOf() hoặc System.arraycopy() hoặc a.clone().

4.6.2. Lỗi ArrayIndexOutOfBoundsException

int[] a = {1, 2, 3};
System.out.println(a[3]);   // LỖI: chỉ số hợp lệ là 0, 1, 2

4.6.3. Lỗi NullPointerException khi mảng chưa khởi tạo

int[] a;
// a[0] = 1;                // LỖI: a chưa được khởi tạo (null)

4.6.4. So sánh mảng: == vs Arrays.equals()

int[] a = {1, 2, 3};
int[] b = {1, 2, 3};

System.out.println(a == b);                    // false (khác tham chiếu)
System.out.println(Arrays.equals(a, b));       // true  (cùng nội dung)

4.7. Truyền mảng vào phương thức và trả về mảng

4.7.1. Truyền mảng vào phương thức

Khi truyền mảng vào phương thức, Java truyền tham chiếu – nghĩa là phương thức có thể thay đổi nội dung mảng gốc. 

public static void tangMoiPhanTu(int[] arr) {
    for (int i = 0; i < arr.length; i++) {
        arr[i] += 1;
    }
}

public static void main(String[] args) {
    int[] a = {1, 2, 3};
    tangMoiPhanTu(a);
    System.out.println(Arrays.toString(a));   // [2, 3, 4]
}

4.7.2. Trả về mảng từ phương thức

public static int[] taoMangChan(int n) {
    int[] kq = new int[n];
    for (int i = 0; i < n; i++) {
        kq[i] = i * 2;
    }
    return kq;
}

4.8. Ví dụ tổng hợp

Chương trình minh họa khai báo mảng, tính toán, sắp xếp, tìm kiếm và mảng hai chiều: 

import java.util.Arrays;
import java.util.Scanner;

public class MangTongHop {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        // 1. Nhập mảng
        System.out.print("Nhap so phan tu: ");
        int n = sc.nextInt();
        int[] a = new int[n];

        for (int i = 0; i < n; i++) {
            System.out.print("a[" + i + "] = ");
            a[i] = sc.nextInt();
        }

        // 2. Thống kê
        int tong = 0, max = a[0], min = a[0];
        for (int x : a) {
            tong += x;
            if (x > max) max = x;
            if (x < min) min = x;
        }
        double tb = (double) tong / n;

        System.out.println("Mang vua nhap: " + Arrays.toString(a));
        System.out.println("Tong: " + tong);
        System.out.println("Trung binh: " + tb);
        System.out.println("Max: " + max);
        System.out.println("Min: " + min);

        // 3. Sắp xếp và tìm kiếm nhị phân
        Arrays.sort(a);
        System.out.println("Sau sort: " + Arrays.toString(a));

        System.out.print("Nhap gia tri can tim: ");
        int key = sc.nextInt();
        int idx = Arrays.binarySearch(a, key);
        if (idx >= 0) {
            System.out.println("Tim thay tai vi tri " + idx);
        } else {
            System.out.println("Khong tim thay");
        }

        // 4. Mảng hai chiều
        int[][] m = new int[3][3];
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                m[i][j] = i * 3 + j + 1;
            }
        }
        System.out.println("Ma tran 3x3: " + Arrays.deepToString(m));

        sc.close();
    }
}

PHẦN BÀI TẬP (4 MỨC ĐỘ)

Bài tập được chia thành 4 mức từ dễ đến khó. Sinh viên nên làm tuần tự từ mức 1 đến mức 4. Mỗi bài đều có lời giải ẩn trong nút "Xem lời giải".

🟢 MỨC 1 – NHẬN BIẾT (Dễ)

Mục tiêu: Ghi nhớ khái niệm mảng, chỉ số, thuộc tính length, khai báo và khởi tạo.

Trắc nghiệm

  1. Chỉ số phần tử đầu tiên của mảng trong Java là:
    A. 1   B. 0   C. -1   D. Tùy khai báo
  2. Thuộc tính nào cho biết số phần tử của mảng a?
    A. a.size()   B. a.length()
    C. a.length   D. a.count
  3. Khởi tạo nào sau đây hợp lệ?
    A. int[] a = new int[5]{1,2,3,4,5};   B. int a[] = {1,2,3};
    C. int[3] a = {1,2,3};   D. int[] a = new int(5);
Xem đáp án
  1. B – Chỉ số bắt đầu từ 0
  2. C – length là thuộc tính, không phải phương thức
  3. B – Cả 2 cách viết int[] a và int a[] đều hợp lệ

Bài tập lập trình

Bài 1.1. Khai báo một mảng 5 số nguyên với các giá trị tùy ý, in các phần tử ra màn hình theo định dạng a[i] = ....

Xem lời giải 
public class Bai1_1 {
    public static void main(String[] args) {
        int[] a = {10, 20, 30, 40, 50};

        for (int i = 0; i < a.length; i++) {
            System.out.println("a[" + i + "] = " + a[i]);
        }
    }
}

Bài 1.2. Khai báo mảng double[] diem = new double[5]; rồi gán giá trị lần lượt là 7.5, 8.0, 6.5, 9.0, 8.5. In ra tất cả phần tử và số phần tử của mảng.

Xem lời giải 
public class Bai1_2 {
    public static void main(String[] args) {
        double[] diem = new double[5];
        diem[0] = 7.5;
        diem[1] = 8.0;
        diem[2] = 6.5;
        diem[3] = 9.0;
        diem[4] = 8.5;

        for (double d : diem) {
            System.out.println("Diem = " + d);
        }
        System.out.println("So phan tu = " + diem.length);
    }
}

🟡 MỨC 2 – THÔNG HIỂU (Trung bình)

Mục tiêu: Hiểu duyệt mảng, tính toán cơ bản, lớp Arrays.

Trắc nghiệm

  1. Đoạn code int[] a = new int[3]; – các phần tử của a có giá trị là:
    A. null   B. 0   C. Giá trị ngẫu nhiên   D. Lỗi biên dịch
  2. Phương thức nào của Arrays dùng để in mảng một chiều?
    A. Arrays.print(a)   B. Arrays.toString(a)
    C. a.toString()   D. Arrays.display(a)
  3. Đoạn code sau in gì? 
    int[] a = {3, 1, 2};
Arrays.sort(a);
System.out.println(Arrays.toString(a));
    A. [3, 1, 2]   B. [1, 2, 3]   C. [3, 2, 1]   D. Lỗi
Xem đáp án
  1. B – int mặc định là 0
  2. B – Arrays.toString(a)
  3. B – sort sắp xếp tăng dần

Bài tập lập trình

Bài 2.1. Nhập vào mảng n số nguyên. Tính tổng, trung bình cộng, tìm giá trị lớn nhất và nhỏ nhất.

Xem lời giải 
import java.util.Scanner;

public class Bai2_1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();

        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            System.out.print("a[" + i + "] = ");
            a[i] = sc.nextInt();
        }

        int tong = 0, max = a[0], min = a[0];
        for (int x : a) {
            tong += x;
            if (x > max) max = x;
            if (x < min) min = x;
        }
        System.out.println("Tong = " + tong);
        System.out.println("TB   = " + ((double) tong / n));
        System.out.println("Max  = " + max);
        System.out.println("Min  = " + min);
        sc.close();
    }
}

Bài 2.2. Nhập mảng số nguyên, đếm số phần tử chẵn, số phần tử lẻ, số phần tử âm, số phần tử dương.

Xem lời giải 
import java.util.Scanner;

public class Bai2_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];

        for (int i = 0; i < n; i++) {
            System.out.print("a[" + i + "] = ");
            a[i] = sc.nextInt();
        }

        int chan = 0, le = 0, am = 0, duong = 0;
        for (int x : a) {
            if (x % 2 == 0) chan++; else le++;
            if (x < 0) am++;
            else if (x > 0) duong++;
        }
        System.out.println("Chan  = " + chan);
        System.out.println("Le    = " + le);
        System.out.println("Am    = " + am);
        System.out.println("Duong = " + duong);
        sc.close();
    }
}

Bài 2.3. Nhập mảng số nguyên, in mảng đảo ngược (không dùng mảng phụ).

Xem lời giải 
import java.util.Arrays;
import java.util.Scanner;

public class Bai2_3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];

        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        for (int i = 0, j = a.length - 1; i < j; i++, j--) {
            int tmp = a[i];
            a[i] = a[j];
            a[j] = tmp;
        }
        System.out.println("Mang dao: " + Arrays.toString(a));
        sc.close();
    }
}

🟠 MỨC 3 – VẬN DỤNG (Khó)

Mục tiêu: Sắp xếp, tìm kiếm nhị phân, mảng hai chiều, sao chép mảng.

Trắc nghiệm

  1. Phương thức Arrays.binarySearch() yêu cầu mảng phải:
    A. Có kích thước chẵn   B. Đã được sắp xếp tăng dần
    C. Chỉ chứa số dương   D. Không có yêu cầu gì
  2. Đoạn code sau in gì? 
    int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
System.out.println(a[0]);
    A. 1   B. 99   C. null   D. Lỗi
  3. Cách nào sao chép nội dung mảng a sang mảng mới?
    A. int[] b = a;   B. int[] b = Arrays.copyOf(a, a.length);
    C. int[] b = a.clone();   D. Cả B và C đều đúng
Xem đáp án
  1. B – Phải sắp xếp tăng dần trước khi tìm kiếm nhị phân
  2. B – b là tham chiếu cùng mảng với a
  3. D – Cả copyOf và clone đều tạo mảng mới độc lập

Bài tập lập trình

Bài 3.1. Nhập mảng số nguyên, sắp xếp tăng dần bằng Arrays.sort(), sau đó nhập một giá trị x và dùng Arrays.binarySearch() để kiểm tra x có trong mảng không, in vị trí nếu có.

Xem lời giải 
import java.util.Arrays;
import java.util.Scanner;

public class Bai3_1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];

        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        Arrays.sort(a);
        System.out.println("Mang sau sort: " + Arrays.toString(a));

        System.out.print("Nhap x can tim: ");
        int x = sc.nextInt();
        int idx = Arrays.binarySearch(a, x);
        if (idx >= 0) {
            System.out.println("Tim thay " + x + " tai vi tri " + idx);
        } else {
            System.out.println("Khong tim thay " + x);
        }
        sc.close();
    }
}

Bài 3.2. Nhập ma trận m x n số nguyên. Tính tổng các phần tử, tìm phần tử lớn nhất, in ma trận chuyển vị (transpose).

Xem lời giải 
import java.util.Scanner;

public class Bai3_2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap m, n: ");
        int m = sc.nextInt(), n = sc.nextInt();

        int[][] a = new int[m][n];
        int tong = 0, max = Integer.MIN_VALUE;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                a[i][j] = sc.nextInt();
                tong += a[i][j];
                if (a[i][j] > max) max = a[i][j];
            }
        }

        System.out.println("Tong = " + tong);
        System.out.println("Max  = " + max);
        System.out.println("Ma tran chuyen vi:");
        for (int j = 0; j < n; j++) {
            for (int i = 0; i < m; i++) {
                System.out.print(a[i][j] + " ");
            }
            System.out.println();
        }
        sc.close();
    }
}

Bài 3.3. Viết phương thức public static int[] locChan(int[] a) trả về mảng chỉ gồm các số chẵn trong mảng đầu vào. Trong main, nhập mảng, gọi phương thức và in kết quả.

Xem lời giải 
import java.util.Arrays;
import java.util.Scanner;

public class Bai3_3 {
    public static int[] locChan(int[] a) {
        int dem = 0;
        for (int x : a) if (x % 2 == 0) dem++;

        int[] kq = new int[dem];
        int k = 0;
        for (int x : a) if (x % 2 == 0) kq[k++] = x;
        return kq;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        int[] chan = locChan(a);
        System.out.println("Cac so chan: " + Arrays.toString(chan));
        sc.close();
    }
}

Mục tiêu: Tổng hợp kiến thức mảng, thuật toán sắp xếp, xử lý mảng nâng cao.

Trắc nghiệm

  1. Với mảng int[][] m = new int[3][];, phát biểu nào đúng?
    A. Mảng có 3 dòng, mỗi dòng 0 cột
    B. Lỗi biên dịch
    C. Các dòng phải được khởi tạo riêng trước khi dùng
    D. Cả A và C đều đúng
  2. Đoạn code sau in gì? 
    int[] a = {1, 2, 3};
int[] b = Arrays.copyOf(a, 5);
System.out.println(Arrays.toString(b));
    A. [1, 2, 3]   B. [1, 2, 3, 0, 0]   C. Lỗi   D. [null, null]
  3. Để sắp xếp mảng chuỗi theo bảng chữ cái, dùng:
    A. Arrays.sort(a)   B. Arrays.sort(a, Comparator.reverseOrder())
    C. Không sắp xếp được   D. a.sort()
Xem đáp án
  1. D – Mảng răng cưa: các dòng chưa khởi tạo (null)
  2. B – copyOf điền 0 cho phần tử thiếu
  3. A – Arrays.sort() sắp xếp theo thứ tự tự nhiên (String đã implement Comparable)

Bài tập lập trình

Bài 4.1. Cài đặt thuật toán sắp xếp nổi bọt (Bubble Sort) để sắp xếp mảng số nguyên tăng dần mà không dùng Arrays.sort().

Xem lời giải 
import java.util.Arrays;

public class Bai4_1 {
    public static void bubbleSort(int[] a) {
        int n = a.length;
        for (int i = 0; i < n - 1; i++) {
            boolean swapped = false;
            for (int j = 0; j < n - 1 - i; j++) {
                if (a[j] > a[j + 1]) {
                    int tmp = a[j];
                    a[j] = a[j + 1];
                    a[j + 1] = tmp;
                    swapped = true;
                }
            }
            if (!swapped) break;   // tối ưu: mảng đã sắp xếp
        }
    }

    public static void main(String[] args) {
        int[] a = {5, 2, 8, 1, 9, 3};
        bubbleSort(a);
        System.out.println(Arrays.toString(a));  // [1,2,3,5,8,9]
    }
}

Bài 4.2. Nhập mảng số nguyên, đếm số lần xuất hiện của mỗi phần tử bằng cách dùng mảng phụ (không dùng Map).

Xem lời giải 
import java.util.Arrays;

        Arrays.sort(a);

Bài 4.3. Nhập hai ma trận A và B cùng kích thước m x n. Tính ma trận tổng C = A + B và in kết quả dưới dạng bảng.

Xem lời giải 
import java.util.Scanner;

public class Bai4_3 {
    public static void main(String[] args) {

        System.out.print("Nhap m, n: ");
        int m = sc.nextInt(), n = sc.nextInt();

        int[][] A = new int[m][n];
        int[][] B = new int[m][n];
        int[][] C = new int[m][n];

        System.out.println("Nhap ma tran A:");

            for (int j = 0; j < n; j++) A[i][j] = sc.nextInt();

            for (int j = 0; j < n; j++) B[i][j] = sc.nextInt();

        System.out.println("Ma tran tong C:");

Bài 4.4. Bài thách thức: Viết chương trình kiểm tra một mảng số nguyên có phải là cấp số cộng không (các phần tử liên tiếp sai khác nhau một hằng số d). Ví dụ: {2, 5, 8, 11, 14} là cấp số cộng với d = 3.

Xem lời giải 
import java.util.Scanner;

public class Bai4_4 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        if (n < 2) {
            System.out.println("Mang qua ngan de kiem tra.");
            return;
        }

        int d = a[1] - a[0];
        boolean laCSC = true;
        for (int i = 2; i < n; i++) {
            if (a[i] - a[i - 1] != d) {
                laCSC = false;
                break;
            }
        }

        if (laCSC) {
            System.out.println("La cap so cong voi d = " + d);
        } else {
            System.out.println("Khong phai cap so cong");
        }
        sc.close();
    }
}

Bài 4.5. Bài tổng hợp: Viết chương trình cho phép người dùng nhập một dãy số nguyên, sau đó hiển thị menu cho phép chọn: (1) In mảng, (2) Tính tổng, (3) Tìm max, (4) Sắp xếp, (5) Thoát. Vòng lặp cho đến khi chọn thoát.

Xem lời giải 
import java.util.Arrays;
import java.util.Scanner;

public class Bai4_5 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        System.out.print("Nhap n: ");
        int n = sc.nextInt();
        int[] a = new int[n];
        for (int i = 0; i < n; i++) a[i] = sc.nextInt();

        int chon;
        do {
            System.out.println("\n=== MENU ===");
            System.out.println("1. In mang");
            System.out.println("2. Tinh tong");
            System.out.println("3. Tim max");
            System.out.println("4. Sap xep");
            System.out.println("5. Thoat");
            System.out.print("Chon: ");
            chon = sc.nextInt();

            switch (chon) {
                case 1:
                    System.out.println(Arrays.toString(a));
                    break;
                case 2:
                    int tong = 0;
                    for (int x : a) tong += x;
                    System.out.println("Tong = " + tong);
                    break;
                case 3:
                    int max = a[0];
                    for (int x : a) if (x > max) max = x;
                    System.out.println("Max = " + max);
                    break;
                case 4:
                    Arrays.sort(a);
                    System.out.println("Da sap xep: " + Arrays.toString(a));
                    break;
                case 5:
                    System.out.println("Tam biet!");
                    break;
                default:
                    System.out.println("Lua chon khong hop le!");
            }
        } while (chon != 5);

        sc.close();
    }
}

Tổng kết chương 4

  • Mảng là tập hợp các phần tử cùng kiểu, kích thước cố định, chỉ số từ 0 đến length - 1.
  • Mảng trong Java là đối tượng, biến mảng lưu tham chiếu; gán mảng là gán tham chiếu.
  • Duyệt mảng bằng for cổ điển (cần chỉ số) hoặc for-each (chỉ đọc).
  • Mảng hai chiều là mảng của các mảng; hỗ trợ cả mảng đều và mảng răng cưa.
  • Lớp java.util.Arrays cung cấp nhiều tiện ích: sort, binarySearch, copyOf, fill, toString, equals, deepToString.
  • Sao chép nội dung mảng dùng Arrays.copyOf(), System.arraycopy() hoặc clone().
  • So sánh nội dung mảng dùng Arrays.equals(), không dùng ==.
  • Cẩn thận với ArrayIndexOutOfBoundsException và NullPointerException.
  • Mảng có thể truyền vào phương thức và trả về từ phương thức; nội dung mảng có thể bị thay đổi từ phương thức.
